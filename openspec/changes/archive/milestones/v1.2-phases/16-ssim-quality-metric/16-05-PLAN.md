# ReportPanel banded SSIM row + Playwright e2e + bundle-budget assertion

<objective>
Ship the visible surface of MTR-03: a "Quality" section in `ReportPanel.tsx` that renders the SSIM score with banded coloring (green ≥ 0.95, yellow ≥ 0.85, red < 0.85) using the constants from 16-02, with `data-testid`/`data-band` attributes for stable e2e selectors. Then add a Playwright spec (`src/tests/ssim-metric.spec.ts`) that drives the full ingest→optimize→SSIM-display flow, verifies selection-thrash preserves the correct final band, and asserts SVG source renders no Quality section (N/A path). Finally, extend `src/tests/build.test.ts` to assert the initial JS gzip chunk remains ≤ 200 KB and the metrics-worker + ssim.js chunks emit as separate assets.

Purpose: Close the phase — this is the only plan that produces user-visible output and is the only plan that gates on the bundle-budget invariant.

Output: One edited component, one new e2e spec, one extended bundle-budget test.
</objective>
