# useMetricsAuto hook + App.tsx mount for selection-driven SSIM dispatch

<objective>
Ship the main-thread orchestrator that closes the loop: subscribe to `$selectedFile`, dispatch `computeSSIM` on the metrics worker when the file is `done` with buffers and no cached metric, apply the CR-02 seqRef stale-drop guard from `useLiveEncode.ts`, and write results back through `setFileMetric` (or `null` on failure). Then mount the hook at `App.tsx` root so it runs for the app lifetime.

Purpose: Turn the passive plumbing from 16-03 into an active behavior — this is what makes the "auto-computes for the currently-selected file when its status === 'done'" language in Phase 16 Success Criterion 2 literally true, and it's what makes re-encode-triggered recomputes fire without any explicit trigger call.

Output: One new hook file, one one-liner edit to App.tsx.
</objective>

Guard order (from 16-RESEARCH.md §Pattern 3):
1. `if (!selected) return`
2. `if (selected.status !== 'done') return`
3. `if (!selected.rawBuffer || !selected.encodedBuffer) return`
