# useMetricsAuto extension — parallel SSIM + Butteraugli dispatch under one seqRef with four-slice buffer discipline

<objective>
Refactor `src/hooks/useMetricsAuto.ts` (Phase 16 owner of the metrics orchestration) so a single effect dispatches BOTH `computeSSIM` and `computeButteraugli` in parallel via `Promise.allSettled` under ONE seqRef ratchet. Cache-hit becomes per-metric (`ssimSettled` / `butSettled`), buffer copies quadruple to four independent `.slice(0)` calls (Comlink detach discipline — RESEARCH §Pitfall 5, PATTERNS §Shared 5), and the useEffect dependency array widens to include `selected?.metrics?.butteraugli` so the effect re-runs when the Butteraugli cache lands.

Critical invariants preserved:
- **CR-02 seqRef stale-drop**: one seqRef guards the WHOLE `Promise.allSettled` batch — selection thrash drops both metrics together, no metric can leak to a stale file.
- **SVG N/A carve-out**: `if (src === 'svg' || tgt === 'svg') return` still applies before dispatch; ReportPanel Quality Section is gated off entirely for SVG (17-05 will render nothing).
- **Failed-compute = null**: catch/rejected-result → `setFileMetric(id, key, null)` so ReportPanel shows "N/A" not perpetual "Computing…".

Purpose: Wave 2 orchestration glue — this is the single-writer boundary between the store, the worker, and the eventual UI (17-05). Every dispatch invariant needed by the e2e test in 17-05 (parallel dispatch, thrash-safe, SVG-skip) lives here.

Output: One edited hook file (~30 lines net change — replace single-dispatch body with parallel-dispatch body).
</objective>

useEffect(() => {
  if (!selected) return
  if (selected.status !== 'done') return
  if (!selected.rawBuffer || !selected.encodedBuffer) return
  if (selected.metrics?.ssim !== undefined) return                  // cache-hit gate (single-key)
  const src = selected.type.toLowerCase()
  const tgt = selected.settings?.codec?.toLowerCase() ?? src
  if (src === 'svg' || tgt === 'svg') return                        // SVG N/A carve-out

  const seq = ++seqRef.current
  const fileId = selected.id
  const rawBuffer = selected.rawBuffer.slice(0)                     // TWO slices — one per Comlink transfer
  const encodedBuffer = selected.encodedBuffer.slice(0)

  void (async () => {
    try {
      const { getMetricsWorker } = await import('@/lib/metrics-worker')
      const worker = getMetricsWorker()
      const job: SSIMJob = { rawBuffer, encodedBuffer, sourceFormat: src as ..., targetFormat: tgt as ... }
      const { mssim } = await worker.computeSSIM(job)
      if (seq !== seqRef.current) return
      setFileMetric(fileId, 'ssim', mssim)
    } catch {
      if (seq !== seqRef.current) return
      setFileMetric(fileId, 'ssim', null)
    }

}, [selected?.id, selected?.status, selected?.encodedBuffer, selected?.metrics?.ssim])

Target Phase-17 hook body (RESEARCH §Pattern 2, PATTERNS §9 delta):

```
useEffect(() => {
  if (!selected) return
  if (selected.status !== 'done') return
  if (!selected.rawBuffer || !selected.encodedBuffer) return
  // Per-metric cache-hit — short-circuit only if BOTH settled (number OR null).
  const ssimSettled = selected.metrics?.ssim !== undefined
  const butSettled  = selected.metrics?.butteraugli !== undefined
  if (ssimSettled && butSettled) return
  const src = selected.type.toLowerCase()
  const tgt = selected.settings?.codec?.toLowerCase() ?? src
  if (src === 'svg' || tgt === 'svg') return                          // unchanged — SVG covers BOTH metrics

  const seq = ++seqRef.current
  const fileId = selected.id
  // FOUR slices — Comlink transfers detach per-buffer; parallel dispatches sharing a buffer
  // would see zero-length on the second call. Main-thread cache untouched (slice copies).
  const rawForSSIM = selected.rawBuffer.slice(0)
  const encForSSIM = selected.encodedBuffer.slice(0)
  const rawForBut  = selected.rawBuffer.slice(0)
  const encForBut  = selected.encodedBuffer.slice(0)

  void (async () => {
    const { getMetricsWorker } = await import('@/lib/metrics-worker')
    const worker = getMetricsWorker()
    const jobShape = { sourceFormat: src as ..., targetFormat: tgt as ... }
    const results = await Promise.allSettled([
      ssimSettled ? Promise.resolve(null) : worker.computeSSIM({ rawBuffer: rawForSSIM, encodedBuffer: encForSSIM, ...jobShape }),
      butSettled  ? Promise.resolve(null) : worker.computeButteraugli({ rawBuffer: rawForBut,  encodedBuffer: encForBut,  ...jobShape }),
    ])
    if (seq !== seqRef.current) return                                 // CR-02: whole batch stale — drop both
    if (!ssimSettled) {
      const r = results[0]
      setFileMetric(fileId, 'ssim',
        r.status === 'fulfilled' && r.value ? (r.value as { mssim: number }).mssim : null)
    }
    if (!butSettled) {
      const r = results[1]
      setFileMetric(fileId, 'butteraugli',
        r.status === 'fulfilled' && r.value ? (r.value as { distance: number }).distance : null)
    }
  })()
}, [selected?.id, selected?.status, selected?.encodedBuffer, selected?.metrics?.ssim, selected?.metrics?.butteraugli])
```

Key deltas vs. Phase 16:
- Cache-hit gate is TWO checks (per-metric), early-return only if BOTH settled.
- Buffer slices go from 2 → 4 (one raw + one enc per metric, per dispatch).
- Single `await worker.computeSSIM(job)` becomes `Promise.allSettled([ssim, butteraugli])`.
- Per-metric skip-when-cached (`ssimSettled ? Promise.resolve(null) : worker.computeSSIM(...)`) so a re-render after Butteraugli cache lands doesn't redundantly recompute SSIM.
- Per-metric result unpack + write gated on `!settled` (avoids double-writing already-cached metrics).
- useEffect deps array gains `selected?.metrics?.butteraugli`.

Backward-compat: The existing `SSIMJob` type import from `@/workers/metrics.worker` still works — 17-03 exports `MetricJob` as an alias. Optionally rename to `MetricJob` for clarity, but not required.

Reused imports (Phase 16 owner): `useEffect`, `useRef`, `useStore`, `$selectedFile` from `@/stores`, `setFileMetric` from `@/stores/files`. No new imports required — `@/workers/metrics.worker` is a type-only import.
