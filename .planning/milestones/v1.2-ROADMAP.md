## Overview

Layers polish + diagnostic transparency + perceptual quality + installable/offline distribution on top of the v1.1 real codec pipeline. Where v1.1 wired the encoders, v1.2 makes the app **honest** (real version + capability values in the Diagnostics tab), **installable** (PWA with offline app shell + on-demand codec cache), **usable from any source** (URL + paste ingest), and **measurable** (real SSIM + Butteraugli perceptual quality scores next to every optimized file, banded green/yellow/red).

The end-to-end promise from PROJECT.md now walks with quality feedback:

> drop folder → settings once → real optimized result → quality scores → ZIP + paste-ready snippets, nothing leaves the browser, installable to desktop/mobile

## Key Accomplishments

1. **The app is honest.** StatusBar version badges + Diagnostics tab surface live svgo + jSquash (png/jpeg/webp/avif/oxipng/resize) + ssim + butteraugli buildHash values injected at build time from `node_modules/<pkg>/package.json`. No more hand-updated string literals; the Copy diagnostics JSON is bug-report-ready.
2. **The app is installable.** `manifest.webmanifest` + hand-rolled `src/sw.ts` ship a real PWA — desktop/mobile install prompts, offline app shell on second visit, codec wasm cached on first use (AVIF's 3.4 MB blob never in precache), and a "New version" toast when the SW upgrades.
3. **The app knows the answer to "how good is this compression?"** Two independent perceptual metrics — SSIM (higher-is-better, banded 0.95/0.85) via `ssim.js@3.5.0`, and Butteraugli (lower-is-better, banded 1.5/3.0) via `@squoosh-kit/visdif@0.2.4` — auto-compute alongside every optimized file. Report panel shows both banded rows with direction-hint captions; SVG source shows N/A.
4. **The bundle budget held under every stack.** 197.2 KB gzipped initial route with Phase 16 (ssim.js) + Phase 17 (visdif) + Phase 14 (sw.ts) all present — 2.8 KB headroom vs. 200 KB PIPE-02 ceiling. Metrics + Butteraugli wasm emit as separate lazy chunks; `bezkrovny` (ssim) and `VisDiff` (visdif) hoist-sentinels asserted absent from the initial chunk in `build.test.ts`.
5. **Ingest expanded to URL + paste.** Toolbar "From URL or paste" and document-level Cmd/Ctrl+V both dispatch through a unified `pickFromClipboard` / `pickFromUrl` pipeline with CORS-honest failure toasts.
6. **Scope discipline held under a substantive pivot.** Phase 17's original "hand-built Emscripten wasm" prescription would have added CI toolchain complexity; research surfaced a maintained npm alternative from the same publisher we already trust for imagequant. User-approved deviation reduced Phase 17 to a Phase-16-shaped extension.
